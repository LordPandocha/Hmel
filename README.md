# Хмель и Соль

Цифровая страница ресторана в Салехарде. React, TypeScript и Vite.

```bash
npm ci
npm run dev
npm run build
```

Данные блюд хранятся в `src/menu.ts`, разрешённые фотографии — в `src/photos.ts`. Сейчас оба набора пусты: доступные публичные источники не позволяют достоверно заполнить позиции с ценами и правомерно разместить фотографии. Посетителям доступны ссылки на меню и галерею в Яндекс Картах. Проверенные источники и ограничения указаны в [SOURCES.md](SOURCES.md).

Сайт опубликован на [GitHub Pages](https://lordpandocha.github.io/Hmel/). Обновления ветки `main` собираются и публикуются через `.github/workflows/deploy.yml`.
