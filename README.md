# Хмель и Соль

Цифровая страница ресторана в Салехарде. React, TypeScript и Vite.

```bash
npm ci
npm run dev
npm run build
```

Данные блюд хранятся в `src/menu.ts`, разрешённые фотографии — в `src/photos.ts`. Сейчас меню показывает явно подписанные демонстрационные карточки без вымышленных цен и снимков: доступные публичные источники не позволяют достоверно заполнить реальные позиции и правомерно разместить фотографии. Когда в `verifiedDishes` появятся подтверждённые блюда, демо-карточки исчезнут автоматически. Посетителям доступны ссылки на меню и галерею в Яндекс Картах. Проверенные источники и ограничения указаны в [SOURCES.md](SOURCES.md).

Сайт опубликован на [GitHub Pages](https://lordpandocha.github.io/Hmel/). Обновления ветки `main` собираются и публикуются через `.github/workflows/deploy.yml`.
